# Мой топ

Android-приложение на Kotlin и Jetpack Compose Material 3. Локальная коллекция хранится в Room, доступна без интернета. В «Настройки → Оформление» доступны системная, светлая и тёмная темы; динамические цвета Android 12+ или акцентная тональная палитра (6 вариантов и собственный HEX); системный шрифт, без засечек, с засечками, узкий, моноширинный и импорт собственного TTF/OTF до 5 МБ. Можно настроить размер текста 90–120%, скругления, компактность карточек и показ позиций. Изменения видны сразу и сохраняются локально между запусками. Загруженный шрифт копируется в приватную папку приложения. Доступны предпросмотр и сброс оформления; другие разделы настроек пока обозначены как будущие возможности.

- Компактные карточки: квадратная обложка слева, название и оценка справа. Нажатие открывает все сведения об игре.
- Добавление и редактирование игры с обложкой, оценкой 0–10, статусом и дополнительными сведениями. Меню ⋮ в карточке позволяет изменить или удалить игру; удаление требует подтверждения.
- Средняя оценка текущей выборки в верхней части главного экрана. Обновляется при поиске, смене фильтров и изменении игр. Если ничего не найдено, отображается «—».
- Поиск по словам в названии, серии, вселенной, жанрах, тегах, разработчиках и платформах. Регистр, повторные пробелы, табуляции, переносы строк и неразрывные пробелы не мешают поиску; все слова запроса должны встретиться в данных игры.
- Сортировка по оценке в обе стороны, названию, порядку добавления и году выпуска. По умолчанию сначала лучшие; одинаковые оценки упорядочены по названию.
- Совместные фильтры по статусу, жанру и минимальной оценке. Номер в карточке — позиция в текущей выдаче.

## Языки и главный экран

Главный экран использует компактную шапку: поиск, сортировку и фильтры, а также строку с количеством найденных игр и средней оценкой. Большая декоративная карточка убрана, чтобы списку игр оставалось больше места.

В «Настройки → Язык» можно выбрать язык системы или один из 13 языков: английский, русский, белорусский, украинский, немецкий, французский, испанский, итальянский, португальский, нидерландский, польский, чешский и румынский. Выбор сохраняется. При смене языка экран пересоздаётся; коллекция не меняется. Для неподдерживаемых языков используется английский интерфейс.

Локализованы экраны, диалоги, подписи доступности, сообщения и TXT-отчёт. Данные игр и структура JSON не переводятся. Полные наборы ресурсов находятся в `res/values*/strings.xml`.

## JSON

В верхнем меню ⋮ доступны отдельное окно импорта JSON с копируемым примером и справкой по полям, а также окно настроек экспорта.

В экспорте можно выбрать JSON или TXT, всю коллекцию или текущую выборку с учётом поиска и фильтров. Порядок соответствует текущей сортировке. Отдельно включаются сведения об игре, история прохождений, мнение и ссылки на обложки. Название, оценка, статус и число прохождений включаются всегда. Отключённые дополнительные поля отсутствуют в JSON; такой файл можно импортировать, но исключённые данные не восстановятся.

TXT — читаемый отчёт в UTF-8: выбранные игры и поля, количество и средняя оценка экспортируемой выборки. Для переноса и восстановления коллекции используется JSON.

Пример: [examples/games.json](examples/games.json).

Основной формат: объект `{"version": 1, "games": [...]}`. Также принимается массив игр без оболочки. Обязательные поля игры: `title`, `rating`, `completions`, `status`. Статусы: `PLAYING`, `COMPLETED`, `REPLAYING`, `DROPPED`. Остальные поля необязательны; неизвестные поля игнорируются. Оценки и часы используют десятичную точку.

Импорт добавляет записи, оставляя текущие игры. Входящие ID заменяются автоматически сгенерированными локальными ID; повторный импорт создаёт копии. Весь файл проверяется до записи, затем игры добавляются одной транзакцией. Ограничения: 10 МБ, 10 000 игр, непустое название, оценка 0–10, неотрицательные прохождения и время игры.

`coverUri` — ссылка на локальное изображение, само изображение в JSON не включается. На другом устройстве или без доступа к исходному файлу отображается иконка-заглушка.

## Основа синхронизации

Настройки → Синхронизация: по умолчанию выключена. Адрес сервера и переключатель сохраняются отдельно от оформления. Клиент принимает базовый HTTPS-адрес без учётных данных, query и fragment. Кнопка проверки использует сохранённый адрес; несохранённый адрес сначала нужно сохранить.

`domain/sync/SyncClient` проверяет настройки до вызова `SyncGateway`. В Koin зарегистрирован `data/sync/UnconfiguredSyncGateway`: он возвращает `SERVER_NOT_AVAILABLE`, не выполняет сетевых запросов и не изменяет коллекцию. Включение переключателя сохраняет намерение пользователя, но не запускает фоновые задачи. Авторизация и сетевой транспорт пока отсутствуют.

Для подключения сервера нужно реализовать и заменить `SyncGateway` в `DataModule`, согласовать API и добавить реальные результаты/состояния синхронизации. До записи данных требуется определить стабильные глобальные ID игр (локальные Room ID для этого не подходят), ревизии, журнал удалений, курсор обмена и разрешение конфликтов. Существующий импорт JSON добавляет копии и не является механизмом синхронизации. После согласования протокола можно добавить транзакционное применение изменений и фоновые задания с повторами. Сейчас нет автоматических запросов, отправки обложек или фиктивного успешного результата.

## Структура и сборка

Проект разделён на семь Gradle-модулей: `app`, `domain`, `data`, `core:ui`, `feature:collection`, `feature:editor`, `feature:settings`. `domain` не зависит от Android; хранилища и форматы файлов находятся в `data`; экраны и ViewModel — в feature-модулях; общие тема, компоненты и переводы — в `core:ui`. В `app` остаются запуск, DI и навигация. Подробности и схема зависимостей: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

Требуются JDK 17+, Android SDK 36 / 36.1 и путь к SDK в `local.properties`.

```sh
bash gradlew verifyArchitecture :app:assembleDebug test lintDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`. Тесты проверяют JSON, валидацию, сортировку, сочетание фильтров, сохранение полей при редактировании, обновление существующей записи, среднюю оценку и текстовый отчёт.
